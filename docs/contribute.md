# How to contribute

This site was scaffolded by an LLM and is still mostly a template. What will make it useful is your experience: which tools helped you, for what, and how? Things that didn't work are worth sharing too.

## Familiar with GitHub?

Edit any page in the [repo](https://github.com/briochemc/academic-llm-guide) (the GitHub icon in the top-right corner takes you there) and open a pull request. Small fixes can be made entirely in the browser.

To preview your changes first, or to check that the site still builds, see [Build the site locally](/build-locally).

## Not familiar with GitHub?

Email what you'd add to [b.pasquier@unsw.edu.au](mailto:b.pasquier@unsw.edu.au?subject=GenAI%20guide) and we'll put it in.
